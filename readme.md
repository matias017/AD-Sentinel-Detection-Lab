# 🛡️ Active Directory & SIEM Detection Lab: Password Spray & AI-Assisted Triage

## 📌 Overview
This project simulates an end-to-end detection and response workflow for an active **Password Spray attack** on an enterprise Active Directory (AD) environment. It demonstrates log ingestion, detection via **Kusto Query Language (KQL)** in **Microsoft Sentinel**, AI-assisted triage, and automated incident response using Python.

---

## 🛠️ Tech Stack & Concepts
* **Identity & Access Management:** Windows Active Directory, Security Event Logs (`4625`, `4624`).
* **SIEM / Analytics:** Microsoft Sentinel, KQL (Kusto Query Language).
* **Automation (SOAR):** Python (AD Account Disablement Simulation).
* **Artificial Intelligence:** Generative AI for threat triage and incident reporting.
